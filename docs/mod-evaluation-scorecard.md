# Mod 성능 평가 지표 (수치)

현재 저장소 baseline 대비 Mod 적용 시 성능을 **0–100점** 및 **1–5 점**으로 표현합니다.

## 1. 차원별 점수 규모

| ID | 차원 | 가중치 | 최대 | 측정 방식 |
|----|------|--------|------|-----------|
| M1 | 컨텍스트 효율 | 15% | 15 | 메인 컨텍스트 토큰 증감률 |
| M2 | 비용 | 15% | 15 | 태스크당 청구 토큰 증감률 |
| M3 | 지연 | 10% | 10 | 총 소요 시간 감소률 |
| M4 | 검증 신뢰 | 15% | 15 | 누락·오탐 감소율 |
| M5 | 리뷰 품질 | 15% | 15 | 중요 이슈 발견률 |
| M6 | 개발 마찰 | 10% | 10 | 추가 조작·재시도 감소 |
| M7 | 보안 표면 | 10% | 10 | 신규 권한·비샌드박스 위험 점수 |
| M8 | 안정성 | 10% | 10 | 세션 실패·부분 로드 비율 |
| | **합계** | **100%** | **100** | |

## 2. 점수 환산

각 차원은 1–5점으로 채점한 뒤 가중치를 곱합니다.

```
차원 점수 = (1–5 점) × (가중치 × 20)
총점 = Σ 차원 점수   (최대 100)
```

| 1–5 점 | 의미 | 예시 (M1, 가중 15%) |
|---------|------|----------------------|
| 5 | 메우 우수 | 15.0 |
| 4 | 우수 | 12.0 |
| 3 | 동일 | 9.0 |
| 2 | 부족 | 6.0 |
| 1 | 나쁨 | 3.0 |

## 3. 판정 기준 (수치)

| 총점 | 판정 | 조건 |
|------|------|------|
| **80–100** | Adopt | 모든 차원 ≥ 3점, M7 ≥ 3 |
| **65–79** | Trial | M7 ≥ 3, M4 ≥ 3 |
| **0–64** | Reject | 평균 부족 또는 M7 < 3 또는 M4 < 3 |
