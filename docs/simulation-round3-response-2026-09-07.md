## 4. 명시적 미수용 · 보정 (상대편이 오해하기 쉬운 지점)

1. **“benign 질문이 Opus(L2)로 올라간다”**  
   - `main` @ `0cbabb8` 재현: **Sonnet(L1)** + Evidence 첨부.  
   - Round 2 의도적으로 **무조건 L2 floor를 넣지 않음**.  
   - → 비용 서술은 **보정**, 오탐 high는 **수정 대상**.

2. **“6/6 전부 high”**  
   - 동일 문장 세트에서 `프로덕션이랑 스테이징 차이가 뭐야?`는 main에서 **low**.  
   - 인용 로컬 SHA와 main 키워드 세트 차이 가능 → **비율 주장은 약화**, 오탐 패턴은 인정.

3. **도메인 overflow를 silent trim으로 바꾸자는 함의**  
   - Round 2/#19는 **top-2 + 드롭 경고** 또는 fail-loud 쪽.  
   - **침묵 트림은 계속 미수용**.

4. **복합 의도를 다중 팩 동시 로드로 바꾸는 것**  
   - S3-05는 **고지만** 수용. 선택 총순서 재설계는 범위 밖.

5. **CLAUDE.md 21B 여유만 더 조이기**  
   - 실측 바닥이 AGENTS 포함이면 잘못된 KPI → S3-01로 **지표 교정**이 본방. 엔트리에 KO 표 욱여넣기 비권장.
