# 수용 사례 점검표

아래 사례는 v1.3 절차의 행동 명세다. A16~A24의 문서 계약과 격리된 양식·정책 fixture는 결정적 수용 테스트로 점검한다. 모델이 실제로 지시를 따르거나 악성 자료의 지시를 거부하는지는 미검증이다. 원본 v1.2 모델 시험은 [역사 증거와 현재 검증 구분](https://github.com/yjj3019/claude/blob/main/skills/ai-delegation-loop/tests/simulation-report.ko.md), 입력과 정답은 [simulation-cases.json](https://github.com/yjj3019/claude/blob/main/skills/ai-delegation-loop/tests/simulation-cases.json)에 보존한다. 실제 업무 성과나 외부 행동 결과를 뜻하지 않는다.

## 완료 조건

- 모든 입력 시나리오에 기대 행동과 명확한 실패 조건이 있다.
- L0~L4를 실제 확인 범위 이상으로 주장하지 않는다.
- 외부에 영향을 주는 행동은 별도의 명시 승인을 필요로 한다.
- 문서 수용 사례 점검과 실제 런타임 검증을 구분해 보고한다.
