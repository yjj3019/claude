# Historical neutral controls

`O-N.md` and `S-N.md` contain byte-identical, task-neutral prose about public
clocks. O-N is the historical Opus neutral arm; S-N is the historical Sonnet
neutral arm. The model prefix separated bookkeeping, not instructions or content.
They held the neutral text constant across models while comparing framework
conditions within the dated Fable diagnostic experiment.

These are preserved remnants of the removed Fable diagnostic runner, not active
FEF task packs, different model prompts or executable tests. The surviving
[PILOT example](../PILOT-RUN.example.json) is a template, not a current result.
See the [evidence index](https://github.com/yjj3019/claude/blob/main/docs/evidence-index.md) and dated
[diagnostic findings](https://github.com/yjj3019/claude/blob/main/docs/opus5-diagnostic-findings.md). Do not infer a
current cross-model ranking or quality improvement from these two files.

Original registration: commit `4cf0cc2`, `config/fable-benchmark.json` used
`claude-opus-4-8` for O-N and `claude-sonnet-5` for S-N, both with
`framework=negative_control`. Those dated IDs are provenance, not current model
recommendations. The associated runner/config are absent from the current tree.
